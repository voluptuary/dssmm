**NEWER EZ-FLASH OMEGA DEFINITIVE EDITION B / BLUE ONLY — HARDWARE UNTESTED. UPDATE AT YOUR OWN RISK.** Do not install on older DE Rev. A/B or Original OMEGA.

Source/build/host and linked ARM/Thumb checks passed. Physical updater acceptance of this larger split image, boot, saves, plugins, NOR timing and runtime stack peaks remain unverified. Flash polling/metadata power-loss limits remain; native 64 MiB handling does not extend generic plugin combinations beyond 32 MiB. Extra custom theme/color slots are excluded.

Historical release; use the latest model-matched download unless comparing or recovering an older installation. Back up the SD card and saves.

### New features

- Brought the current Merkin Mix frontend to BLUE's vendor hardware foundation, retaining native 64 MiB/5G handling, drivers, FPGA resources and NOR allocation.
- Added name/header-code/mirrored artwork, long filenames, marked transparency and optimized cached/scaled previews.
- Added optional remembered cheats by **exploitz86**, group-menu foundations by **SkillerCMP** adapted by **exploitz86**, themed NOR progress and SD-side artwork-folder records.

### New fixes

- Bounded game/plugin sizes, exact reads/closes, compressed payloads and stack-safe boot; restored small headerless plugins and rebuilt records after failed loads.
- Staged saves/settings and checked filenames; bounded PSRAM/NOR patch copies and final-block padding.
- Added NOR erase/program/catalog readback and reserve-before-publish ordering; tightened cheat sizes/rows, removed the black launch strip and checked BLUE update staging.
