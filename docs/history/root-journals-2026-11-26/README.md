# Root journal archive — 2026-11-26

This directory preserves the complete root `AGENTS.md`, `HANDOFF.md` and
`PROGRESS.md` as they stood immediately before the 2026-11-26 documentation
restructure. They are verbatim historical records; do not edit them.

The restructure removed duplication between the three root files and gave each
one purpose:

- `AGENTS.md` — mission, operating rules, architecture/merge workflow, release
  policy and roadmap.
- `PROGRESS.md` — condensed running log of milestones, dead ends, fixes,
  workarounds, staged items and future tactics, newest first.
- `HANDOFF.md` — cold-start rebuild/recovery instructions plus a short recent
  task log for an agent taking over after an abrupt stop.

Detailed per-project history was never owned by the root logs and remains in the
each project's `docs/` (including `docs/history/`), release evidence JSON and
git history. The original pre-shared-tree branch journals remain under each
project's `docs/history/pre-shared-tree/`.
