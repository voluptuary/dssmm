### New features

- No new user-facing features; this build focused on fixes and optimizations.

### New fixes

- Enforced the 2 MiB image limit without leaving stale oversized output; cleaned up failed first saves and distinguished existing-save errors from missing files.
- Improved flash-operation feedback, game-list refresh after format, progress/confirmation redraws and redundant-info-write avoidance.
- Prevented cheat records inheriting earlier values, restored established settings-save polling and consolidated settings readers without intended behavior changes.

- Optional browser wrapping.
