**EZ-FLASH OMEGA Definitive Edition Rev. A/B only.** Do not install on Original OMEGA or the newer DE B / BLUE.

Owner feedback confirmed normal boot, saving and settings persistence; SD rename power-loss recovery was not hardware-qualified. Avoid interruption during writes.

Historical release; use the latest model-matched download unless comparing or recovering an older installation. Back up the SD card and saves.
