**EZ-FLASH OMEGA Definitive Edition Rev. A/B only.** Do not install on Original OMEGA or the newer DE B / BLUE.

The fragmentation fix passed host tests; highly fragmented physical SD cards were not qualified. Subsequent v7.4.6b hardware feedback did not reproduce the earlier settings-persistence issue; cheat parsing remained hardware-unverified.

Historical release; use the latest model-matched download unless comparing or recovering an older installation. Back up the SD card and saves.

### New features

- Updated About-screen branding to DS Style Merkin Mix and displayed the build number.

### New fixes

- Rejected fragmented ROM/RTS files whose FPGA FAT tables exceed the fixed transfer buffer, rather than sending corrupted tables.

### Summary of past features

- Mirrored SD artwork with custom/built-in fallbacks, selective marked transparency and refreshed console/splash art.
- Optional browser wrapping.

### Summary of past fixes

- Safer NOR catalog/install/delete checks and interrupt restoration; checked SD/save/RTS I/O, bounded paths/cheats and PSRAM patching across 8 MiB banks.
- Long-filename identity, folder display and mirrored-art aliases, fewer directory scans, revised stack/heap placement and BIOS-off launch.
- Reliable image-size guards, first-save cleanup and existing-save error handling; improved flash/format feedback and cheat parsing, with established settings polling retained.
