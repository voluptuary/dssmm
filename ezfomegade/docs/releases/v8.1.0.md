### New features

- No new user-facing features; this build focused on artwork rendering.

### New fixes

- Optimized transparency scans with aligned pixel pairs, selecting DMA for opaque rows while retaining exact `0x8000` masking and avoiding a second scan of transparent rows.

### Summary of past features

- Mirrored SD artwork with custom/built-in fallbacks, selective marked transparency and refreshed console/splash art.
- Optional browser wrapping.
- Merkin Mix About-screen branding and build number.

### Summary of past fixes

- Safer NOR catalog/install/delete checks and interrupt restoration; checked SD/save/RTS I/O, bounded paths/cheats and PSRAM patching across 8 MiB banks.
- Long-filename identity, folder display and mirrored-art aliases, fewer directory scans, revised stack/heap placement and BIOS-off launch.
- Reliable image-size guards, first-save cleanup and existing-save error handling; improved flash/format feedback and cheat parsing, with established settings polling retained.
- Bounded fragmented-ROM/save-state FAT transfers.
