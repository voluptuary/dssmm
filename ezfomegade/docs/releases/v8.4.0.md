**EZ-FLASH OMEGA DEFINITIVE EDITION REV. A/B ONLY.**

Do not install on Original OMEGA or the newer DE B / BLUE.

Production and software/emulator regression checks passed. No new physical Rev. A/B MiGoomba validation is recorded. Existing flash polling, interrupted NOR catalogs and SD rename/power-loss limits remain; avoid interruption during writes.

Back up the SD card and `.esv` saves. Old emulator save states are not guaranteed compatible; prefer in-game battery saves when transitioning.

Download **`ezkernelnew.bin`** (2,030,600 bytes). GitHub supplies source archives automatically.

SHA-256: `5037473f5992f745e8d29d2df34e12996a76aaac2ccde51786f99b5432827d48`

### New features

- Replaced the built-in GB/GBC emulator with **MiGoomba v0.1** by **michyprima**, based on Jagoomba Color, Goomba Color and Goomba. DE-specific clock/rumble behavior is retained.

### New fixes

- Added embedded-emulator size/alignment guards and loader regression checks for exact game offsets, DMA copies and cache bounds.

### Summary of past features

- **FrankieT19's DS Style v7.5 foundation and separate v8.0 UI work:** Start screen, selection effects, sounds/pop-ups, loading ring/fade, Auto theme, View grouping, Open SYSTEM, boot preferences and favorites shortcuts.
- List, List + Art and horizontal/vertical carousels; title/box art, side previews, configurable borders/corners, favorites, recents and last-played startup.
- Name-matched, header-code, mirrored and nested NOR artwork; custom/per-extension fallbacks, marked transparency, console icons, square/wide art and CUSTOM Only rounded corners.
- Themes, accent colors, customizable launcher/Start layouts, multilingual settings/help, Thai/Chinese support and a text/Markdown viewer; Clean list, wrap scopes, 12/24-hour clocks and hidden-system controls.
- Optional remembered cheats, off by default, by **exploitz86**, with collapsible groups originating with **SkillerCMP** and adapted by **exploitz86**.
- Themed NOR writing progress and selected-game save-recovery artwork; kernel installation from `/SYSTEM/KERNELS`; faster artwork rendering/indexed lookup and 832 bytes less working-RAM use.

### Summary of past fixes

- Safer staged saves/settings with previous-file retention on write failures; checked save/copy reads, full-width sizes, close failures, backups and valid Chinese/mixed-case paths.
- Bounded game/plugin loading, PSRAM-bank handling, NOR patch writes and NES detection/patching; malformed/incomplete input and stale detection are rejected.
- Safer plugin boot/stack handoff and decompression; restored small headerless plugins, correct argument names and directory rebuilds after failed loads; removed the black launch strip.
- Corrected transparency/art alignment, thumbnail-cache reuse, carousel wrap/borders, root/NOR artwork and fragmented/large-folder browsing, including recents/empty-list limits.
- Corrected settings/language rendering and persistence, cheat-group selection/scrolling and file-size checks, NOR hints/errors/format/delete feedback, software boot and save-type labels.
