**EZ-FLASH OMEGA Definitive Edition Rev. A/B only.** Do not install on Original OMEGA or the newer DE B / BLUE.

The original notes did not establish complete hardware qualification. Avoid interruption during cartridge/SD writes.

Historical release; use the latest model-matched download unless comparing or recovering an older installation. Back up the SD card and saves.

### New features

- Mirrored SD artwork lookup with custom/built-in fallbacks, marked-thumbnail transparency and refreshed console icons/splash art. The folder limit remains 255 files; the [thumbnail scraper fork](https://github.com/voluptuary/ds-style-multisystem-thumbnail-scraper/releases) prepares compatible artwork.

### New fixes

- Checked NOR catalog/title bounds, source/header reads, FF padding, metadata publication, interrupt restoration and trim arithmetic; restricted deletion to the verified newest title and fixed format/delete redraws and lockups.
- Checked SD/save/RTS sizes, reads/writes/closes and pending recovery; cleaned up failed first saves and bounded paths, save names and malformed cheat records.
- Corrected PSRAM patch writes across 8 MiB banks, rejected odd addresses, initialized folder counts and aligned installer expectations with shipped package names.
