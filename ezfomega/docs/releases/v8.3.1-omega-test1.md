**ORIGINAL EZ-FLASH OMEGA ONLY — HARDWARE UNTESTED. UPDATE AT YOUR OWN RISK.** Do not install on DE Rev. A/B or the newer DE B / BLUE.

Source/build/host checks passed; installation, boot, saves, plugins, cheats/states and NOR still need cartridge testing. Native/plugin combinations remain limited to 32 MiB; NOR deletion retains the newest-title restriction. Flash success/polling and metadata power-loss recovery remain limited; extra custom theme/color slots are excluded.

This partial backport lacks later fast artwork/settings paths and SD-side nested NOR artwork records. Cheat snapshots lack the save-file replacement safeguards. The About screen uses the original development label `Merkin Mix 8.3.1-omega-dev`.

Historical release; use the latest model-matched download unless comparing or recovering an older installation. Back up the SD card and saves.
