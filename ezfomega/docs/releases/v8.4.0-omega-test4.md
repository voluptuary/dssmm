# DS Style Merkin Mix 8.4.0 — Original OMEGA Test 4

**ORIGINAL EZ-FLASH OMEGA ONLY — HARDWARE UNTESTED. UPDATE AT YOUR OWN RISK.**

Do not install on DE Rev. A/B, the newer DE B / BLUE, or another model.

Software regression checks passed; installation, boot, saves, plugins, NOR timing and runtime stack peaks remain physically unverified. Native/plugin combinations remain limited to 32 MiB. NOR deletion keeps the newest-title restriction; flash polling and metadata power-loss limits remain. Extra custom theme/color slots are excluded.

Back up the SD card and `.esv` saves. Old emulator save states are not guaranteed compatible; prefer in-game battery saves when transitioning.

Download **`ezkernel.bin`** (2,054,824 bytes) with the correct model-compatible `SYSTEM` setup. GitHub supplies source archives automatically.

SHA-256: `8d37e4f80e5c5cc68332406e95f3fbe345c3afeea9b4b11cb0df19b383baef00`

### New features

- Replaced the built-in GB/GBC emulator with **MiGoomba v0.1** by **michyprima**, based on Jagoomba Color, Goomba Color and Goomba. The Original OMEGA ezo variant intentionally does not save emulator settings when its menu closes.

### New fixes

- Added embedded-emulator size/alignment guards and loader regression checks for exact game offsets, DMA copies and cache bounds.

### Summary of past features

- **FrankieT19's Original OMEGA DS Style v8.0 foundation:** DS menus, Start screen, themes, sounds, selection effects and launch presentation.
- List, List + Art and horizontal/vertical carousels, title/box art and side previews; favorites, recents, last-played startup, Light/Dark/Auto themes and accent colors.
- Name/header-code/mirrored artwork, long filenames, marked transparency, per-extension defaults and CUSTOM Only rounded corners; cached/scaled previews, optimized lookup/rendering and refreshed splash/help art.
- Indexed long-filename identities, Clean list and On, Not SYSTEM wrapping; readable settings, Chinese/Thai support and the text/Markdown viewer.
- Optional remembered cheats, off by default, by **exploitz86**, with collapsible groups from **SkillerCMP**, adapted by **exploitz86**.
- Themed NOR progress and SD-side NOR artwork paths; staged save/settings replacement and 832 bytes less working-RAM use.

### Summary of past fixes

- Bounded NES detection/patch writes, malformed artwork checks and save-file sizes; corrected Chinese paths and stopped save loading on close errors.
- Checked raw/compressed plugin payloads, decompression selection, boot copies and arguments; rebuilt directory records after failed PSRAM loads and removed incomplete copies.
- Corrected thumbnail-cache reuse, carousel VRAM/code bounds, transparency/rounding, settings aliases, Thai table alignment and menu button hints.
- Safer save/settings replacement, exact SD reads, PSRAM-bank and patch boundaries, NOR input/catalog/allocation checks and FF padding; preserved cheat-group selection/visible-row fixes.
